# Couchpad site

Support, privacy and landing pages for App Store Connect.

Publish with GitHub Pages:
1. Create a public repository named `couchpad` on GitHub and upload the files from this folder.
2. Repository Settings › Pages › Source: Deploy from a branch › `main` / root › Save.
3. After a minute the site is at `https://<your-github-login>.github.io/couchpad/`.
4. Put that address into `AppLinks.site` in the app and into App Store Connect:
   - Support URL: `…/support.html`
   - Privacy Policy URL: `…/privacy.html`
