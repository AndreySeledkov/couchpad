# Cozyware site — https://cozyware.app

Studio site for Cozyware with a page per app, in English (root), Ukrainian (`uk/`) and Russian (`ru/`).
Published from the public repository [AndreySeledkov/couchpad](https://github.com/AndreySeledkov/couchpad)
with GitHub Pages and the custom domain `cozyware.app` (the `CNAME` file). The old address
`andreyseledkov.github.io/couchpad/…` redirects to the new domain.

| Page | Use |
|---|---|
| `/` | Studio home |
| `/couchpad/` | Couchpad page (Marketing URL) |
| `/couchpad/support.html` | Support URL in App Store Connect |
| `/couchpad/privacy.html` | Privacy Policy URL in App Store Connect |
| `/support.html`, `/privacy.html` | Legacy URLs submitted with version 1.0 — kept working |
| `/review/` | Demo video for App Review |

Mail: `hello@cozyware.app` and `support@cozyware.app` are forwarded to the owner's Gmail by Cloudflare Email Routing.
DNS lives in Cloudflare (4 × `A` GitHub Pages IPs + `www` CNAME, DNS only; MX/TXT for Email Routing).

All pages are generated by `build.py` (texts for Couchpad are in `texts_couchpad.py`) — run `python3 build.py`.
When Couchpad is live in the App Store set `APP_LIVE = True` in `build.py`: the "Coming soon" button becomes
the App Store link and the Smart App Banner is added. To publish, push to `main`.

Adding another app: add a section in `build.py`, `/<app>/index.html`, `support.html`, `privacy.html`, and a card on the home page.
