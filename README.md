# Couchpad site

Support, privacy and landing pages for App Store Connect.
Published from the public repository [AndreySeledkov/couchpad](https://github.com/AndreySeledkov/couchpad)
with GitHub Pages at https://andreyseledkov.github.io/couchpad/

| Page | App Store Connect field |
|---|---|
| `support.html` | Support URL |
| `privacy.html` | Privacy Policy URL |
| `index.html` | Marketing URL (optional) |

To publish changes, copy the files to the `couchpad` repository and push to `main`
(Settings › Pages › Deploy from a branch › `main` / root).
