# Couchpad site

Support, privacy and landing pages for App Store Connect, in English (root), Ukrainian (`uk/`) and Russian (`ru/`).
Published from the public repository [AndreySeledkov/couchpad](https://github.com/AndreySeledkov/couchpad)
with GitHub Pages at https://andreyseledkov.github.io/couchpad/

| Page | App Store Connect field |
|---|---|
| `support.html` (`uk/support.html`, `ru/support.html`) | Support URL |
| `privacy.html` (`uk/privacy.html`, `ru/privacy.html`) | Privacy Policy URL |
| `index.html` | Marketing URL (optional) |

All pages are generated by `build.py` — edit the texts there and run `python3 build.py`.

To publish changes, copy the files to the `couchpad` repository and push to `main`
(Settings › Pages › Deploy from a branch › `main` / root).
